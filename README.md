# Regex · Trainer BTS SIO

**🔗 En ligne :** https://neroclaw.github.io/regex-trainer/ · **📦 Code :** https://github.com/NeroClaw/regex-trainer

---

Trainer de révision des expressions régulières, du cours depuis zéro jusqu'aux exercices corrigés par exécution réelle.

## Contenu
- 9 leçons progressives : littéraux, classes, quantifieurs, ancres, groupes, alternatives, lookaround, drapeaux, pièges.
- 30 exercices avec correction vérifiée par exécution réelle du moteur (pas de correction approximative).
- Mode Focus (par défaut) : une unité à l'écran, navigation ← →.

## Technique
Site statique : `index.html` + `course.js` + `data.js` + `app.js` + `styles.css`, aucune dépendance de build.
